## Things we deliberately do NOT use

* **Browser Web Speech recognition** (`SpeechRecognition`/`webkitSpeechRecognition`): in Chrome
  and Edge it streams audio to the vendor's cloud. Speech recognition is done by Vosk on the
  local server instead.
* **Network TTS voices**: only `speechSynthesis` voices with `localService === true` are used
  (Windows tested: "Microsoft David - English (United States)", installed with the OS).
  This PC has no Telugu OS voice, so Telugu speech is generated by Piper on the local server
  (`/api/tts`, loopback only, origin-checked).
* **ONNX Runtime `AzureExecutionProvider`**: the installed onnxruntime wheel lists it. Every
  `InferenceSession` in this project pins `CPUExecutionProvider` explicitly; a test
  (`test_onnx_sessions_never_use_cloud_providers`) enforces this.
* CDNs: the frontend loads no external scripts, fonts or styles.
* MediaPipe was not installed. It remains an optional local baseline (Apache-2.0), but it is not
  needed because the torchvision baseline covers Model A.
* Ultralytics YOLO-pose was rejected: AGPL-3.0 would impose licence obligations on the app.
